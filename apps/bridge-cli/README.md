# jean-bridge

`jean-bridge` connects a local machine to a Workroom room through an outbound WebSocket. It lets approved room tasks delegate work to local agents such as Codex while keeping credentials and command execution on the user's machine.

## Install

```bash
npm install -g @jean/bridge-cli
```

## Pair from a room

Use the pairing command generated by the Workroom room UI:

```bash
jean-bridge pair --api-url https://your-workroom-api.example --code <pairing-code>
```

Use `--no-start` to pair now and start later:

```bash
jean-bridge pair --api-url https://your-workroom-api.example --code <pairing-code> --no-start
jean-bridge start
```

## Commands

```bash
jean-bridge help
jean-bridge doctor --api-url https://your-workroom-api.example
jean-bridge pair --api-url <url> --code <code>
jean-bridge login
jean-bridge agents list
jean-bridge start
```

Run `jean-bridge doctor --api-url <url>` before pairing to check the local Node.js
runtime, Codex CLI auth, and Workroom API `/health`. Use `--skip-codex` for
non-Codex local agents and `--skip-api` for a local-only preflight.

## Security model

- The bridge opens an outbound WebSocket; Workroom does not open a shell on the user's machine.
- Room-scoped session tokens are stored in `~/.jean-bridge/state.json`.
- Local actions are limited to commands declared in `~/.jean-bridge/config.yaml`.
- Applying files and running checks require human approval from the room.
